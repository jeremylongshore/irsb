# IRSB Agent Passkey Documentation

This directory contains technical documentation for the IRSB Agent Passkey service.

## Document Filing System

Documents follow the pattern: `XXX-CC-TYPE-description.md`

### Prefixes

- `001-099`: Sequential documents (ADRs, AARs, reports)
- `6767-*`: Evergreen documents (architecture, guides, plans)

### Category Codes

- `DR` - Decision Records (ADRs)
- `AA` - After Action Reports
- `AT` - Architecture/Technical specifications
- `OD` - Operations/Deployment guides
- `PP` - Project Plans
- `GU` - User Guides

### Document Types

- `ADR` - Architecture Decision Record
- `REPT` - Report
- `SPEC` - Specification
- `GUID` - Guide
- `PLAN` - Plan
